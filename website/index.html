Features

Alles, was du brauchst. Nichts, was nervt.

HUD-Module

FPS, CPS, Koordinaten, Keystrokes und Rüstung mit Haltbarkeit. Jedes Modul einzeln schaltbar.

HUD-Editor

Module per Drag & Drop verschieben. Sie rasten an Bildschirmrändern und an der Mitte ein.

Smooth Zoom

C halten, und mit dem Mausrad stellst du die Stärke ein. Weicher Übergang und Cinematic-Kamera.

Fullbright

Höhlen ohne Fackeln. Hell über die Lightmap statt über einen wackeligen Gamma-Hack.

Eigenes Hauptmenü

Klarer Titelbildschirm mit Panorama und Voxira-Branding. Im Mod-Menü abschaltbar, falls du Vanilla willst.

Installation

In zwei Minuten startklar.

  1. Profil anlegenCurseForge → Minecraft → Create Custom Profile. Version 26.3, Modloader Fabric.
  2. Fabric APIIm Profil auf Add More Content, nach „Fabric API“ suchen und auf Install klicken.
  3. Voxira reinlegenJAR herunterladen, dann im Profil auf ⋮ → Open Folder → mods und die JAR hineinziehen.
  4. SpielenAuf Play klicken, im Spiel öffnet Right Shift das Mod-Menü.
  1. Fabric installierenFabric Installer starten, Version 26.3 wählen und auf Install klicken.
  2. Fabric APIFabric API für 26.3 herunterladen.
  3. Mods-OrdnerWin + R → %appdata%\.minecraft\mods. Fabric API und die Voxira-JAR hineinlegen.
  4. SpielenIm Launcher das Profil fabric-loader-26.3 wählen und auf Spielen klicken.

FAQ

Häufige Fragen

Kann ich damit gebannt werden?

Voxira enthält keine Cheats, nur Anzeige- und Komfort-Funktionen wie HUD, Zoom und Fullbright. Manche Server verbieten aber einzelne Features, Fullbright oder Zoom zum Beispiel. Lies im Zweifel die Regeln des Servers.

Welche Minecraft-Version wird unterstützt?

Aktuell Minecraft 26.3 mit Fabric. Weitere Versionen folgen später.

Läuft das mit Sodium oder Iris?

Voxira ist als leichte Fabric-Mod gebaut und sollte neben gängigen Performance-Mods laufen. Wenn etwas kollidiert, melde es bitte als Issue.

Gibt es eine Forge-Version?

Nein, Voxira setzt bewusst nur auf Fabric. Fabric ist schneller bei neuen Versionen und schlanker.

Ich habe einen Bug gefunden.

Eröffne ein Issue auf GitHub und häng am besten logs/latest.log an.
