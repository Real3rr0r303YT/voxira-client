Features

Everything you need. Nothing you don't.

HUD modules

FPS, CPS, coordinates, keystrokes and armor with durability. Toggle each one on its own.

HUD editor

Drag modules wherever you want. They snap to the screen edges and the center.

Smooth Zoom

Hold C and scroll to set the zoom level. Smooth transition and cinematic camera.

Fullbright

Caves without torches. Bright via the lightmap instead of a fragile gamma hack.

Custom main menu

A clean title screen with panorama and Voxira branding. Switch it off in the mod menu if you prefer vanilla.

Open Source

Installation

Ready in two minutes.

  1. Create a profileCurseForge → Minecraft → Create Custom Profile. Version 26.3, mod loader Fabric.
  2. Fabric APIIn the profile, click Add More Content, search for “Fabric API” and click Install.
  3. Add VoxiraDownload the JAR, then click ⋮ → Open Folder → mods and drop it in.
  4. PlayClick Play. In game, Right Shift opens the mod menu.
  1. Install FabricRun the Fabric Installer, pick version 26.3 and click Install.
  2. Fabric APIDownload Fabric API for 26.3.
  3. Mods folderWin + R → %appdata%\.minecraft\mods. Put Fabric API and the Voxira JAR in there.
  4. PlaySelect the fabric-loader-26.3 profile in the launcher and click Play.

FAQ

Frequently asked questions

Can I get banned for using it?

Voxira contains no cheats, only display and comfort features like the HUD, zoom and fullbright. Some servers do ban specific features such as fullbright or zoom, so check the server rules if in doubt.

Which Minecraft version is supported?

Minecraft 26.3 on Fabric for now. More versions will follow.

Does it work with Sodium or Iris?

Voxira is a lightweight Fabric mod and should run alongside common performance mods. If something conflicts, please open an issue.

Is there a Forge version?

No. Voxira deliberately targets Fabric only, which is lighter and quicker to support new versions.

I found a bug.

Open an issue on GitHub and attach logs/latest.log if you can.
